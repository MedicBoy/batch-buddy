# Native iPhone experiment

This is the first native SwiftUI shell. The GitHub workflow creates an **unsigned** IPA using Xcode on a GitHub macOS runner. Download it and use Sideloadly on Windows to sign/install it with your Apple Account.

This first build proves the free build-and-install path. It does not yet include screen sharing. The next native milestone is a user-initiated ScreenCaptureKit stream for iOS 18+, which must stay visible, consent-driven, and advisory-only.
